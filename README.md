# Facebook / Meta API Client & Token Utility

A premium developer interface and testing environment for Meta WhatsApp Business & Graph APIs.

## Features
- **Meta Graph API Proxy**: Bypasses CORS restrictions seamlessly.
- **WhatsApp API Local Tester**: Test WhatsApp sending APIs and parse responses dynamically.
- **Premium Dark Mode UI**: Rich, interactive developer dashboard.

## Tech Stack
- **Backend**: Node.js, Express
- **Frontend**: HTML5, Vanilla CSS, JS

## Getting Started
1. Run `npm install`
2. Run `npm start`
3. Open `http://localhost:3000`
